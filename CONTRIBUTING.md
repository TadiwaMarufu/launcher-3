# Contributing

EmoLauncher is developed incrementally.

Before opening a pull request:

1. Keep launcher behavior functional.
2. Prefer reusable Compose components.
3. Avoid hardcoded device dimensions.
4. Preserve accessibility and performance.
5. Run unit tests and the Android build.
6. Do not commit credentials, keystores or generated secrets.

Visual work should follow the monochrome, calm and spatial design language.
